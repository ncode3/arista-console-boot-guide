# Contributing to Arista Console Boot Guide

Thank you for contributing! This project aims to be the definitive open-source guide for Arista switch configuration.

## Quick Start

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit: `git commit -m "Add feature"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## What We're Looking For

✅ Real-world configuration examples  
✅ Troubleshooting guides  
✅ Ansible automation playbooks  
✅ Integration guides (OpenShift, Kubernetes)  
✅ Security hardening procedures  
✅ Documentation improvements  

## Guidelines

- Test on actual hardware when possible
- Include clear explanations
- Add comments to configuration examples
- Follow existing formatting
- Be respectful and helpful

## Code of Conduct

Be kind, be inclusive, be helpful. We're all learning together.

---

No contribution is too small. Thank you!
