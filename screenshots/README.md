# Screenshots

This directory contains screenshots from the Arista switch boot sequence.

## Files

Place your boot sequence screenshots here with the following naming convention:

- `01_boot_start.jpg` - Initial kernel boot messages
- `02_pci_enumeration.jpg` - PCI device initialization
- `03_user_creation.jpg` - Linux user account setup
- `04_qemu_init.jpg` - QEMU virtualization layer startup
- `05_login_prompt.jpg` - First login attempt
- `06_boot_complete.jpg` - System fully operational

## Usage

Reference screenshots in documentation using relative paths:

```markdown
![Boot Start](../screenshots/01_boot_start.jpg)
```

## Format

- **Format**: JPG or PNG
- **Resolution**: At least 1920x1080 recommended
- **Size**: Keep under 2MB per image if possible
- **Quality**: Clear, readable text is essential
